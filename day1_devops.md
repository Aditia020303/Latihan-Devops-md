definisi devops
Devops merupakan development operations, yang bertujuan mempercepat pengembangan software, integrasi, testing, deployment dan monitoring.

fungsi
dengan menggunakan devops semuanya menjadi otomatis (CI/CD, Docker, Kubernetes, IaC)

Perbedaan Devops dengan sysadmin
system admin bertugas manajemen server, instalasi software, backup dan patch sedangkan devops fokussnya pada CI/CD, container, infrastruktur as code. dan sysadmin biasanya manual sedangkan devops otomatis.

3 alas an kenapa devops penting
evisiensi meningkatkan kecepatan inovasi, merilis update aplikasi lebih cepat dan meningkatkan kualitas produk.
